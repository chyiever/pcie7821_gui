# 2026-7-17 滤波配置与数据流

## 1. 本次版本目标

本次修改后，Tab2 中的 `FILTER` 开关和 `Filter` 参数不再只影响 Tab2 Time-Space 图。它们同时作为 Tab1 phase 时域曲线的显示侧滤波配置来源。

需要特别区分的是：Tab1 phase 时域曲线会使用 Tab2 FILTER 配置进行显示侧滤波；保存数据不使用该滤波；Tab1 phase PSD 也不使用该滤波。

## 2. 总体数据流

PHASE 数据进入软件后的主链路如下：

```text
采集线程 read_phase_data()
    -> phase 空间裁剪 crop
    -> 完整块分发 _dispatch_full_data()
        -> Tab3 TCP 队列
        -> 保存线程 save_block()
    -> GUI 最新显示快照 _publish_latest_display_data(copy)
        -> _on_phase_data()
            -> 可选 Rad 显示转换
            -> _update_phase_display()
                -> Tab1 phase 时域曲线显示
                -> Tab1 phase PSD
                -> Tab2 Time-Space 显示
```

完整块分发和 GUI 显示快照在采集线程内已经分成两条链路。GUI 显示快照使用 `np.array(..., copy=True)` 复制，因此后续显示侧处理不会反向修改保存队列中的完整块。

## 3. 保存数据

保存数据仍然来自 `MainWindow._handle_full_data_block()` 接收到的完整采集块，并通过 `BlockBasedFileSaver.save_block(data)` 进入后台保存线程。

保存链路不经过以下 GUI 显示处理：

- 不经过 Tab2 FILTER 滤波。
- 不经过 Tab1 phase 时域曲线滤波。
- 不经过 Tab1 PSD 计算。
- 不经过 Rad 显示转换。
- 不经过 Tab2 Time-Space 的距离范围裁剪、Space DS、Time DS 或图像缓冲转置。

因此，PHASE 保存文件保存的是当前底层相位上传链路输出后的 `int32` 数据块。它可能已经包含 FPGA/DLL 相位链路本身的处理，以及采集线程中的 phase 空间裁剪；但不会包含 GUI 中的 Rad 转换和本次新增的 Tab1/Tab2 显示侧滤波。

## 4. Rad 显示转换

`Rad` 仍然是显示侧转换，不改变保存数据。

在 `_on_phase_data()` 中，若 `Rad` 勾选开启，程序会先执行：

```text
display = int32_phase * pi / 32767
```

随后 Tab1 phase 时域曲线、Tab1 phase PSD 和 Tab2 Time-Space 都基于这份 Rad 转换后的显示数据继续处理。

若 `Rad` 关闭，Tab1 phase 时域曲线、Tab1 phase PSD 和 Tab2 Time-Space 使用未转弧度的 phase 显示快照。无论 `Rad` 是否开启，保存数据始终保存未做 Rad 转换的原始 phase `int32` 块。

## 5. Tab1 Phase 时域曲线滤波

本次新增的行为是：Tab1 phase 时域曲线读取 Tab2 的 `FILTER` 开关和 `Filter` 参数，并使用这些参数对 Tab1 波形曲线的数据进行显示侧实时滤波。

实现要点如下：

- 配置来源：Tab2 的 `FILTER` 开关和 `Filter` 文本框。
- 状态对象：Tab1 在 `MainWindow` 内维护独立的 `RealtimeTimeAxisFilter`。
- 状态隔离：Tab1 只共享 Tab2 的配置，不共享 Tab2 Time-Space 图自己的滤波器状态。
- 滤波方向：对 `frames x points` 数据沿时间轴滤波；多通道时按 `frames x (points * channels)` 向量化滤波。
- 触发范围：只用于 `plot_curve_1.setData(...)` 的 Tab1 phase 时域曲线显示数据。
- 失效处理：若 Filter 参数为空、格式错误或超过 Nyquist 频率，Tab1 波形滤波会跳过，波形回退为未滤波显示数据。

Tab1 独立滤波状态会在以下情况重置：

- 采集开始。
- Tab1 波形显示开关切换。
- Tab2 Time-Space 参数变化，包括 FILTER 开关或 Filter 参数变化。
- 滤波参数、采样率或输入列数变化。
- FILTER 关闭或参数无效。

这样做可以避免 Tab1 和 Tab2 的 IIR 状态互相污染，也避免在用户切换滤波配置后继续沿用旧状态。

## 6. Tab1 Phase PSD

Tab1 phase PSD 不使用 Tab2 FILTER，也不使用 Tab1 phase 时域曲线的滤波结果。

PSD 输入仍然来自 `_update_phase_display()` 中未经过 Tab1/Tab2 FILTER 的 `display_data` 或 `space_data`：

- Phase `Mode=space` 时，PSD 使用某个空间点跨帧得到的未滤波时间序列。
- Phase `Mode=time` 时，PSD 使用当前 phase 显示快照中的未滤波一帧数据。

如果 `Rad` 开启，PSD 输入会是 Rad 转换后的显示数据；如果 `Rad` 关闭，PSD 输入会是未转弧度的 phase 显示数据。PSD 内部仍然由 `spectrum_analyzer.py` 使用 `scipy.signal.welch()` 计算，并保留 `detrend='constant'` 去 DC 和实时平均逻辑。这些属于 PSD 分析流程，不属于 Tab2 FILTER。

## 7. Tab2 Time-Space 滤波

Tab2 Time-Space 仍然使用自己的滤波状态。其处理顺序保持为：

```text
Tab2 update_data(frame x point)
    -> Distance Range 裁剪
    -> Space DS
    -> Tab2 自己的 RealtimeTimeAxisFilter
    -> Time DS
    -> 转置为空间 x 时间
    -> 写入 Tab2 滚动图像缓冲
```

Tab2 滤波只改变 Tab2 图像缓冲，不改变保存数据，也不改变 Tab1 PSD。Tab2 与 Tab1 波形共享的是开关和参数文本，不共享 IIR 状态。

## 8. Raw、Monitor 和 Tab3

Raw 显示链路不使用 Tab2 FILTER。

Monitor 图不使用 Tab2 FILTER。

Tab3 TCP phase 发送链路来自完整 phase 块分发，不经过 Rad、不经过 Tab1 波形滤波、不经过 Tab2 Time-Space 滤波。

## 9. 最新行为汇总

| 数据路径 | Rad | Tab2 FILTER 参数 | Tab2 FILTER 状态 | 说明 |
|---|---:|---:|---:|---|
| 保存 PHASE 数据 | 否 | 否 | 否 | 保存当前相位上传链路输出的 `int32` 完整块。 |
| Tab3 TCP PHASE 数据 | 否 | 否 | 否 | 使用完整 phase 块，不经过 GUI 显示处理。 |
| Tab1 phase 时域曲线 | 是，若勾选 | 是，FILTER 开启时 | 否，Tab1 独立状态 | 本次新增，使用 Tab2 配置但独立滤波。 |
| Tab1 phase PSD | 是，若勾选 | 否 | 否 | 使用未经过 Tab1/Tab2 FILTER 的显示数据做 Welch PSD。 |
| Tab2 Time-Space 图 | 是，若勾选 | 是，FILTER 开启时 | 是，Tab2 独立状态 | 只影响 Tab2 图像缓冲。 |
| Raw 时域/频谱 | 不适用 | 否 | 否 | 不使用 Tab2 FILTER。 |
| Monitor 图 | 不适用 | 否 | 否 | 不使用 Tab2 FILTER。 |

## 10. 现场验证建议

建议按以下顺序验证：

1. PHASE 模式，`Rad` 开启，Tab2 `FILTER` 关闭，确认 Tab1 phase 时域曲线、PSD 和保存文件行为与旧版本一致。
2. PHASE 模式，Tab2 输入 `1-` 并开启 `FILTER`，确认 Tab1 phase 时域曲线发生滤波变化，Tab1 phase PSD 不随之变化。
3. 同一组数据下开启保存，确认保存文件仍为未 Rad、未 FILTER 的 phase `int32` 数据。
4. 切换 Tab2 `Filter` 参数，例如 `-10`、`2-10`、`0.1-`，确认 Tab1 phase 时域曲线随参数变化并且不会和 Tab2 图像状态互相影响。
5. 输入超过 Nyquist 的参数，确认 Tab2 按钮提示无效，Tab1 phase 时域曲线回退为未滤波显示数据，PSD 和保存不受影响。
